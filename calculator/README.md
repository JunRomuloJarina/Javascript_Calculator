# Simple JavaScript Calculator

A clean, responsive web-based calculator built using vanilla HTML, CSS, and JavaScript.

## Features

- **Basic Arithmetic**: Supports addition, subtraction, multiplication, and division.
- **Parentheses**: Support for complex expressions using brackets.
- **CSS Grid Layout**: A modern, structured design for better button alignment.
- **Keyboard Support**: Allows users to type expressions directly into the display.
- **History Log**: Keeps track of previous calculations accessible via the "View History" button.
- **Input Validation**: Prevents invalid sequences like double operators or double decimals.

## How to Use

1. Clone or download the repository.
2. Navigate to the `calculator` folder.
3. Open `index.htm` in any modern web browser.
